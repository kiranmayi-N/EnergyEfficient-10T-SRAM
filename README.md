# EnergyEfficient-10T-SRAM
This project focuses on the low-power VLSI design of a 10-transistor SRAM cell with single-ended read/write operations, optimized for near-threshold voltage using Tanner EDA (S-Edit, T-Spice and W-Edit)
## 📘 Abstract

This project proposes an energy-efficient single-ended 10T (SE10T) near-threshold SRAM design using **adiabatic positive feedback methods** to enhance **read stability** and **writability**. Simulation was carried out in **Tanner EDA**, targeting low-power System-on-Chip (SoC) applications.

**Keywords**: SRAM, CMOS, 10T SRAM, Adiabatic Logic, PFAL, Tanner EDA

## 🔍 Project Overview

The proposed 10T SRAM incorporates:
- **Adiabatic positive feedback logic**
- **Built-in read-assist scheme**
- **Power gating**
- **Single-ended read/write** mechanisms

This reduces energy while maintaining read stability at near-threshold voltages. Simulations verify reduced power-delay product compared to conventional 6T SRAM cells.
